# 區網聚會題庫

建議在主持人電腦開啟 **http://localhost:3000/admin**，用表單管理題庫；也可以手動編輯 `server/question-bank.json`。這是後端專用檔案，不能放在 `public/`、`src/` 或 `dist/`；不需要 Supabase，也不用部署網站。

## 表單管理

- 左側選擇題目，或按「新增題目」「複製這題」。新題及副本預設停用，整理完成後再啟用。
- 新增或編輯歌曲時，YouTube 連結為必填；直接貼上 YouTube 網址，輸入提示與答案的起訖分秒，按各自的「試播」確認。
- 正確歌詞使用多行輸入框，按 Enter 換行就是下一句；空白行儲存時忽略，格數自動產生；本題滿分可自行輸入正數，支援一位小數（0.1～1000000）。標點與空格會原樣顯示在管理頁預覽及玩家題目中，作為提示，不占作答格、不影響判分。例如「問天涯，望斷了天涯」會顯示為三格、逗號、五格。
- 勾選滿分欄位旁的「試玩題」，即可當作玩法講解範例。試玩題照常計算正確率、逐字批改、本題得分及排名，但不加入隊伍累計總分；結果頁會明確標示。未設定此欄位的舊題目預設為正式題。
- 後台題目列表與編輯區、主持人頁、玩家猜題頁及結果頁都會顯示正式歌曲的「第幾首歌」。試玩只顯示「試玩」，不占正式歌曲編號；未啟用題目也不占編號。排序或啟用狀態改變時會重新計算，新房間使用新順序，已建立的房間保留原順序。
- 上下箭頭調整順序，啟用開關決定題目是否加入遊戲。
- 按「刪除這題」後需確認；尚未儲存前，可按「復原刪除」恢復最近刪除的一題。最後按「儲存題庫」才會寫入檔案，已建立的房間不受影響。
- 可以儲存空題庫或全部停用，但建立新房間前至少需要一題有效且啟用的題目。
- 儲存立即對新房間生效，不需重啟；已建立的房間保留當時題庫。
- 管理 API 僅允許 loopback 連線及 localhost／127.0.0.1 網址。用手機或 `10.0.0.101` 區網網址開啟，不能讀取或儲存題庫。主機本身其他使用者可存取此本機管理頁，沒有另外設定帳號密碼。
- 編輯期間若另一個視窗或檔案已更新，儲存會拒絕覆蓋。請先保留自己的修改，再按「重新載入」。

以下是手動編輯檔案時的欄位說明。

每個陣列項目是一道題。`enabled: true` 的題目按檔案順序出題；`false` 保留但不加入遊戲。

| 欄位 | 用途 |
| --- | --- |
| `id` | 唯一識別碼，不可重複 |
| `enabled` | 是否加入遊戲 |
| `title`、`artist` | 揭曉後顯示的名稱，可自行填寫 |
| `points` | 自訂滿分，0.1～1000000，最多一位小數 |
| `practice` | `true` 為試玩題，不加入累計；`false` 或省略為正式題 |
| `prompt` | 例如「接出接下來兩句」 |
| `cue` | 公開提示，玩家與電視都看得到，不能填正確答案 |
| `videoId` | YouTube 網址 `v=` 後的 11 字元，例如 `FDeRzYjRGvY` |
| `questionClip` | 提示影片的起訖秒數 |
| `answerClip` | 揭曉影片的起訖秒數 |
| `lineLengths` | 預期每句格數，例如 `[8, 8]`；伺服器會比對歌詞檢查 |
| `lines` | 每個陣列元素為一句正確歌詞，標點可以保留；每句最多 50 字，總長含標點及空格最多 300 字元 |

目前實際啟用的第一題：

```json
{
  "id": "FDeRzYjRGvY-45",
  "enabled": true,
  "title": "天涯",
  "artist": "任賢齊",
  "points": 10,
  "prompt": "接出接下來兩句",
  "cue": "請接出影片暫停後的兩句歌詞",
  "videoId": "FDeRzYjRGvY",
  "questionClip": { "startSeconds": 45, "endSeconds": 79 },
  "answerClip": { "startSeconds": 79, "endSeconds": 86 },
  "lineLengths": [8, 8],
  "lines": ["問天涯，望斷了天涯", "贏得了天下，輸了她"]
}
```

時間以整支影片的起點計算：`0:45 = 45`、`1:19 = 79`、`1:26 = 86`。可使用小數秒；內嵌串流受播放器、網路與瀏覽器排程影響，不是逐幀精準的影片剪輯。

## 主持人流程

主持人的遊戲與管理頁請都用 `http://localhost:3000` 開啟，手機仍掃區網網址的 QR Code。實測同一影片在 `127.0.0.1` 來源回報 150，但在 `localhost` 可正常準備播放，因此遊戲現在會把手機邀請網址與主持人網頁來源分開。這不保證所有影片都可播放，仍需試播；錯誤時可重試或重載播放器。

1. 主持人在電腦的題庫管理頁選擇對應題目，按提示片段的「試播」，再按播放器的播放按鈕。請讓管理頁留在電腦的獨立螢幕，不要顯示到電視；YouTube 播放器保持可見。
2. 播放器以設定的起訖時間播放，例如 45–79 秒，到終點停止。電視遊戲畫面及手機不顯示提示影片，但聆聽階段就會顯示每句格數、作答格、標點與空格提示；這時還不能輸入答案。
3. 主持人確認提示播放結束後，在遊戲畫面按「提示播完，開始作答」，後端才啟動倒數。題庫試播與遊戲倒數各自獨立，不會自動同步；播放提示時請只操作播放器，避免修改正在進行的題目。
4. 每題可選 2／3／5 分鐘。玩家輸入時自動暫存草稿，仍保留手動提交按鈕。倒數歸零會自動截止，進入「正在收取各隊答案」，手機停止編輯並補送當前內容；全部收齊或約 1.5 秒收取期限結束後，使用各隊最新草稿自動提交並鎖定，等待主持人按「揭曉答案」才判分及公布歌詞。主持人也可提前按「截止並揭曉答案」，收取完即揭曉。斷線或未及回覆的裝置只能使用最後成功同步到伺服器的草稿；未同步的內容無法保證收取。已手動提交後又修改的草稿，以最新內容為準。結果頁會標記「截止時自動提交」。
5. 電視顯示答案片段播放器，先準備設定的片段，再嘗試自動播放（例如 79–86 秒）。瀏覽器可能阻擋有聲自動播放，這時按「播放答案片段」。若 YouTube 回報錯誤，可按「重試播放」或「重新載入播放器」，不會再次計分。
6. 答案片段播完後，按「查看各隊答案」。電視與手機會同步顯示獨立的作答結果頁，逐行列出隊名、原答、紅筆批改、正確率與本題得分，依本題得分排序（同分並列）。錯字用紅線刪除、上方補正確字；漏字標 ∧ 並補字，多字標 × 並刪除。分數固定顯示一位小數。
7. 主持人從結果頁進入下一題或公布最終排名。只有揭曉時會計分，切換結果頁不會重複加分；手機不播放影片。一支手機代表一隊，加入時填的隊名／暱稱就是結果頁的隊名。

播放器載入失敗、影片不允許嵌入時，畫面會提供錯誤說明及「在 YouTube 開啟」。外部分頁不能由遊戲控制切點，需要主持人手動暫停；回到遊戲仍可正常開放作答與揭曉。

本次在內嵌播放器試播 `FDeRzYjRGvY`，回報不允許嵌入（YouTube 錯誤 150）。目前請用外部分頁手動控制 0:45–1:19 及 1:19–1:26；若要在遊戲內自動控制，需換成允許嵌入的影片並再次試播。沒有下載影片或繞過來源的嵌入限制。

影片不下載或儲存在電腦上；遊戲雖在區網運作，主持人的電腦仍需要網際網路才能連 YouTube。

## 修改後生效

題庫在建立新房間時重新讀取並複製到該房間。儲存後建立新房間即可使用，不需重啟，也不會改動進行中的房間。只改 JSON 不需要重新 build；有修改前端時才需要 `npm run build`。

題庫有錯字數、無效影片 ID、錯誤時間、重複 id 或無效滿分時，儲存或讀取會拒絕並指出有問題的題目。

### 中途加入歌曲與手動改分

儲存歌曲後，切至主持人畫面開啟的「房間控制台」，按「重新讀取題庫」並選「加入本場」。既有題目不會被題庫更新覆寫，可調整尚未播放的順序。控制台也能選擇已批改題目修正隊伍得分，須填原因；原始批改和改分紀錄保留，總分按差額更新。試玩題修正得分不計入總分。

### 可接受的用字差異

計分與逐字批改會接受以下等同字組：你／妳、他／她／它／牠、的／地／得、啊／阿、嗯／恩、喔／哦／噢。每組內任兩字都算對，原始輸入保留；其餘同音字仍扣分，多字及漏字仍計算錯誤。
