# 接著唱 · Song Party

同場聚會猜歌詞遊戲。主持人電腦接電視，玩家用手機掃碼加入，不用註冊或下載 App。

## 啟動

需要 Node.js 18.12 以上。

```powershell
npm install
npm run build
npm start
```

保持終端機開啟；啟動指令是 **npm start**，不是 npx start。開發時可改用 `npm run dev`。

| 頁面 | 主持人電腦網址 | 用途 |
|---|---|---|
| 遊戲／投影 | http://localhost:3000 | 建立房間、顯示題目與排名 |
| 題庫管理 | http://localhost:3000/admin | 編輯歌曲、歌詞、分數與影片片段 |
| 房間控制台 | http://localhost:3000/control | 播放提示、控制流程、中途加歌及改分 |

**題庫與控制台包含答案，請留在電腦操作，不要投影。**

手機與電腦連同一個 Wi-Fi，再掃描房間 QR Code。手機不要開 localhost；啟動訊息不列出區網網址，QR Code 仍會自動產生。連不到時，請看 [Windows 防火牆與連線排查](docs/lan-troubleshooting.md)。

## 怎麼玩

1. 建立房間，讓各隊掃碼加入（最多 30 隊，每隊一支手機）。
2. 在 Control 點突出顯示的「播放提示片段」，聽完按「開始作答」。可先選 2／3／5 分鐘，後續題目沿用。
3. 玩家輸入歌詞，草稿自動同步；超出格數的字以灰色顯示，仍會提交。
4. 時間到自動截止並收取答案，等待主持人揭曉；也可提前截止揭曉。斷線時採最後成功同步的內容。
5. 揭曉時投影播放答案片段，Control 原本的播放會停止。按「查看各隊答案」後顯示批改及分數，再進入下一題。

## 題庫與計分

- 新增或編輯歌曲必須填寫有效的 YouTube 連結。
- 正確歌詞直接按 Enter 分行，空白行儲存時忽略；每句最多 50 字，合計含標點及空格最多 300 字元。
- 分數可自訂至小數點一位；試玩題照常批改，但不加入總分。
- 依錯字、漏字、多字比例扣分，不比速度。繁簡、標點及空格不扣分。
- 放寬字組：**你／妳、他／她／它／牠、的／地／得、啊／阿、嗯／恩、喔／哦／噢**；其他同音錯字仍扣分。
- 題庫儲存後，新房間使用新版；現有房間可從 Control 逐首或一鍵加入尚未加入的已啟用歌曲，也可調整待播順序。
- Control 可手動改分並保留原因與紀錄，也可在房間選擇頁清除已結束房間。

題庫保存在 `server/question-bank.json`。影片使用 YouTube 串流，主持人電腦需有網際網路。詳細設定見 [題庫說明](docs/question-bank.md)。

## 更新與限制

程式更新後執行 `npm install`、`npm run build`，再重新啟動 `npm start`，並重新整理各裝置頁面。只修改題庫或文件不需要重新建置。

**房間與分數存在記憶體，重啟伺服器會清除；題庫保留。** 本版供家中區網使用，尚未部署雲端。

技術：React、Vite、Node.js HTTP API、SSE、OpenCC。測試指令：`npm test`。
