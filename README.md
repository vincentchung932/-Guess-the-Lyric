# 接著唱 · Song Party

同場聚會猜歌網頁。主持人的電腦接電視，玩家用手機掃碼加入，無須註冊。

## 啟動

需求：Node.js 18.12 以上。建議使用仍受支援的 Node.js LTS。

```powershell
npm install
npm run dev
```

主持人的電腦請開啟 **http://localhost:3000** 建立房間，題庫管理使用 **http://localhost:3000/admin**，讓兩邊 YouTube 播放器使用相同網頁來源。QR Code 會自動使用電腦的實體區網 IP（例如 `http://192.168.1.10:3000`），手機連同一個 Wi-Fi 後掃碼加入。程式會排除常見虛擬網卡；如果電腦有多張實體網卡，請確認產生的邀請網址是手機可達的那一張。手機本身不要開 localhost。

若手機無法開啟，請參考下方「手機連不到：Windows 防火牆設定」。電腦使用延伸桌面時，將主持人瀏覽器移到電視上。

```powershell
npm test
npm run build
npm start
```

`PORT` 環境變數可調整連接埠，預設 3000。

## 手機連不到：Windows 防火牆設定

曾遇到「電腦可以開啟遊戲，但 iPhone 掃碼或輸入網址後無法載入」的情況，調整 Windows 防火牆允許區網連線後即可加入。電腦自己能開啟網址，不代表防火牆已允許其他裝置連入。

先確認以下事項：

1. 電腦已執行 `npm start`（第一次需先 `npm run build`），並保持終端機開啟。
2. 手機與電腦連同一個家用網路，手機不要使用行動網路或訪客 Wi-Fi。
3. 手機使用 QR Code 中的區網網址，例如 `http://10.0.0.101:3000`，不是 `localhost`。可在電腦執行 `ipconfig`，查看目前 Wi-Fi 網卡的 IPv4 位址；不要選 VPN 或虛擬網卡的位址。IP 換了就要使用新的網址。
4. 主持人電腦仍使用 `http://localhost:3000`，題庫管理及房間控制台分別為 `/admin`、`/control`。

### 允許 Windows 防火牆連入

第一次啟動若跳出 Windows 防火牆提示，允許 Node.js 存取目前使用的網路。Windows 的網路設定檔可能是「私人」或「公用」；只勾私人，但目前 Wi-Fi 被判定為公用時，手機仍可能連不到。

若之前沒有允許，請在**主持人電腦**以系統管理員身分開啟 PowerShell，新增只允許本機子網路存取 Node.js TCP 3000 的規則：

```powershell
$songNode = (Get-Command node -ErrorAction Stop).Source
New-NetFirewallRule -DisplayName 'Song Party - Node TCP 3000 LAN' -Direction Inbound -Action Allow -Program $songNode -Protocol TCP -LocalPort 3000 -RemoteAddress LocalSubnet -Profile Private,Public
```

規則同時涵蓋私人與公用設定檔，但來源限制在本機子網路。若程式使用其他連接埠，將 `3000` 改成對應的 `PORT`。更新或重裝 Node.js 導致執行檔路徑改變時，也需要更新規則的程式路徑。

完成後，在手機重新開啟區網網址或重新掃碼測試。這項設定不需要關閉整個防火牆，也不需要設定路由器連接埠轉送。

若仍無法連線，確認路由器沒有啟用 AP／用戶端隔離，並檢查是否有明確封鎖 Node.js 的防火牆規則；明確封鎖可能優先於允許規則。請辨識規則用途後再調整，不要直接刪除系統、安全軟體或開發工具的隔離規則。

不再使用時，可在系統管理員 PowerShell 移除上述規則：

```powershell
Remove-NetFirewallRule -DisplayName 'Song Party - Node TCP 3000 LAN'
```

## 第一版玩法

1. 電腦建立房間，選擇每題 2／3／5 分鐘（預設 2 分鐘）。
2. 手機掃碼、填暱稱加入（每房最多 30 位）。一支手機也可代表一隊。
3. 主持人在電腦另一個畫面的題庫管理頁試播提示片段，電視與玩家手機僅顯示聆聽提示。片段結束後，主持人手動按「提示播完，開始作答」啟動倒數。
4. 玩家連續輸入歌詞，內容會自動暫存草稿，也可手動按提交。倒數歸零會自動截止，輸入框停止編輯，系統短暫收取各隊最新內容後鎖定，等待主持人按「揭曉答案」。主持人也可提前按「截止並揭曉答案」。沒按提交的草稿也會自動提交並計分。斷線或未及回覆的裝置，使用伺服器最後成功暫存的內容。請留意手機的草稿同步狀態。
5. 主持人揭曉，電視只公布歌詞並播放答案片段，不顯示戰況、各隊得分或個人批改。按「查看各隊答案」後，才同步公布結果與累計分數：逐行列出隊名、原答、紅筆批改與本題得分，依本題分數由高到低排序，同分並列。
6. 結果頁按「下一題」繼續，最後一題則按「公布最終排名」。得分顯示到小數點第一位；錯字刪除並在上方補正確字、漏字標 ∧ 並補字、多字標 × 並刪除。

## 固定題庫與播放

題庫在 `server/question-bank.json`，由 `server/questions.js` 驗證並讀取。現在啟用一題 YouTube 題（10 分、兩排各 8 格），另保留三題停用的童謠示範。答案只在後端，揭曉前不傳給任何瀏覽器。

範例影片 `FDeRzYjRGvY`：題目片段 0:45–1:19，答案片段 1:19–1:26。片段以 YouTube IFrame API 控制，揭曉時若有聲自動播放被阻擋，按播放按鈕即可。

在主持人電腦開啟 **http://localhost:3000/admin**，即可用表單新增、編輯、複製、排序、停用題目，並試播提示與答案片段。本題滿分可自由輸入（正數，最多一位小數）；勾選「試玩題」仍會批改及計算本題得分，但不加入隊伍累計，適合講解玩法。儲存後新房間立即生效，進行中的房間保留舊題庫，不需重啟。管理 API 僅限 localhost／127.0.0.1 及 loopback 連線，手機無法讀取題庫答案。管理頁會顯示答案，請在電腦另一個分頁準備，不要投到電視。

詳細欄位與操作見 [題庫說明](docs/question-bank.md)。也可手動編輯 JSON；不需重新 build。影片須允許嵌入，實際切點與歌詞仍應在聚會前試播確認。YouTube 影片直接串流，不儲存在遊戲後端。主持人遊戲畫面公開顯示，沒有提前預覽答案的介面。

## 計分

OpenCC 將繁簡體統一為簡體，移除標點、空白、控制字元，再計算 Levenshtein 編輯距離。插入、刪除、替換各算一個錯誤。以下字組互相視為正確：你／妳、他／她／它／牠、的／地／得、啊／阿、嗯／恩、喔／哦／噢；其餘同音字仍扣分。原始作答用字會保留，放寬字組不畫紅線。

`得分 = max(0, 滿分 × (1 - 編輯距離 / 正確答案字數))`

四捨五入至一位小數。所有歌詞行合併計分，總分按題目累加；不加速度分。

## 架構與目前限制

- React + Vite 前端、Node HTTP API、Server-Sent Events（SSE）推送。玩家提交走 HTTP。這是單向通知即可滿足的場景，不必使用 Kafka 或雙向 WebSocket。
- 後端掌控房間狀態、截止、權限與計分。答案以版本序號避免舊請求覆寫，計分只能在鎖定後執行一次。
- **房間資料目前存於單一 Node 程序記憶體**，伺服器重啟後消失。房間建立 12 小時後移除。瀏覽器 sessionStorage 保存本分頁身分，重新整理可恢復，關閉分頁後可能失去身分。
- 目前決定採用家中區網，不部署雲端、不接 Supabase。電腦自己啟動 Node 伺服器，手機連同 Wi-Fi；主持人的電腦需要網際網路播放 YouTube。
- 上線前應增加持久化、正式的 HTTPS／房間存取控制、代理環境流量限制，以及實際併發負載測試。現有簡單 IP 限速供本機試玩，並非公網防濫用完整方案。
- 使用系統字型，不需額外下載字型。

## 目前房間控制台

建立房間後，在主持人畫面右上角按「房間控制台」，會另開私人操作分頁；電視繼續顯示原本的主持人畫面。控制台包含答案，請勿投影或分享控制台連結。

- 共用題庫 `/admin` 儲存新歌後，在控制台按「重新讀取題庫」→「加入本場」，歌曲接在目前房間最後。加入時複製歌曲設定，不自動覆寫本場既有歌曲。
- 可上移、下移或移除尚未播放的歌曲；目前及已完成歌曲鎖定。結束後不能追加歌曲。
- 控制台可播放提示片段，並開始作答、截止、揭曉及進入下一題。
- 在「主持人手動修正分數」選擇已批改題目與隊伍，輸入 0 到本題滿分的分數（最多一位小數）和原因。每次只更新總分差額，保留系統批改及修正紀錄；試玩題仍不計總分。
- 控制台需主持人身分；玩家不能讀取待播歌曲或改分。房間仍保存在記憶體，重新啟動伺服器會清除比賽紀錄。

房間控制台的「一鍵加入全部歌曲」會依題庫順序加入已啟用且尚未在本場的歌曲（包含試玩題），不受搜尋條件影響；已存在的歌曲不重複加入。新增後請先重新讀取題庫，確認待加入首數。

### 作答時間與房間清理

主持人可在「仔細聽，準備接著唱」畫面或房間控制台選擇 2、3、5 分鐘，從本題起沿用到後續歌曲。開始作答後不能修改本題倒數。玩家超出歌詞格數的輸入會接在最後一行，以灰色格子顯示，仍會提交並計入多字扣分。

控制台按「選擇其他房間」後，可按「清除已結束房間」。確認後移除已結束房間的答案、分數與修正紀錄，進行中的房間及共用題庫保留。

控制台播放器會依比賽階段切換：聆聽階段突出「播放提示片段」；作答與鎖定階段仍可播放提示，但不突出；揭曉後只顯示「播放答案片段」。進入揭曉或切換歌曲時會停止並移除控制台原本的播放器，避免和投影畫面同時播放；答案片段需在控制台手動點選才播放。
